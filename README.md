# Cookbook
# Модуль 1: Виртуальный склад / Холодильник 
 - Как пользователь, я хочу добавлять и редактировать продукты в своем виртуальном холодильнике, чтобы отслеживать, что у меня есть в наличии.
 
 - Файлы: Ingredient / PantryManager
# Модуль 2: База рецептов
 - Как пользователь, я хочу просматривать рецепты с пошаговыми инструкциями и списком ингредиентов, чтобы выбирать, что приготовить.

 - Файлы: Recipe / RecipeStep
# Модуль 3: Движок подбора рецептов
 - Как пользователь, я хочу видеть рецепты, которые можно приготовить прямо сейчас, чтобы не тратить время на проверку каждого ингредиента вручную.

 - Файлы: RecipeMatcherService
# Модуль 4: Список покупок и Хранилище
 - Как пользователь, я хочу автоматически получать список покупок для выбранного рецепта, чтобы быстро докупить недостающие продукты.

 - Файлы: ShoppingList / RecipeStorage
